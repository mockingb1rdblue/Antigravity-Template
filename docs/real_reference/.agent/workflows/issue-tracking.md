# /issue-tracking

## Rule (Pillar #2)
🚨 **All bugs or features MUST be logged in `docs/issues-and-enhancements.md` before coding begins.**

## Format
- **Issues**: `ISS-[auto-incrementing-number]: [Description]`
- **Enhancements**: `ENH-[auto-incrementing-number]: [Description]`

## Process
1.  **Log**: Add entry to `docs/issues-and-enhancements.md`.
2.  **Tag**: Categorize as Bug, Enhancement, or Task.
3.  **Implement**: Reference the ID in commit messages (e.g., `fix: ISS-001 - resolve world resolver crash`).
