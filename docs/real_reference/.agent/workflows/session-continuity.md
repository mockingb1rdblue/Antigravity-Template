# /session-continuity

## Rule (Pillar #2)
🚨 **Maintain `STATUS.md` as the authoritative source of truth for project state.**

## Process
1.  **Update**: Update `STATUS.md` at the end of every session or after significant milestones.
2.  **Content**:
    - **What Was Accomplished**: Detailed bullet points.
    - **Current State**: Code status, environment, and latest commit.
    - **How to Continue Work**: Steps for the next agent/developer.
    - **What's Left to Do**: High-level road map.
3.  **Stewardship**: Ensure all dependencies and build statuses are current.
