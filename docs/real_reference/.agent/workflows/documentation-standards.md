# /documentation-standards

## Rule (Pillar #4)
🚨 **Every feature must include user-friendly, non-technical documentation.**

## Requirements
- **Persona**: Write for a non-technical player/owner.
- **Tone**: Professional, clear, and helpful.
- **Location**: `docs/` directory.
- **Reference**: Maintain the `README.md` and `docs/glossary.md` as shared context for non-technical users.
