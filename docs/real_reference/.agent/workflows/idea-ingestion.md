# /idea-ingestion

## Process
1.  **Capture**: Log new ideas in `docs/ideas.md`.
2.  **Review**: During planning, evaluate feasibility and impact.
3.  **Promotion**: If approved, move to `MASTER_PLAN.md` backlog.
4.  **Spec**: Create a technical spec in `docs/specs/` before implementation.
