# Antigravity Template Project

This project was initialized using the Antigravity Template.

## Project Structure

- `.agent/`: Agent-specific configurations and workflows.
- `docs/`: Project documentation.
- `scripts/`: Automation and utility scripts.
- `src/`: Source code.
- `brain/`: Persistent memory and knowledge base (managed by Antigravity).

## Getting Started

1. Define your project goals in `MASTER_PLAN.md` (to be created).
2. Start building your implementation logic in `src/`.
3. Use specialized agents in `.agent/` to automate your workflows.
